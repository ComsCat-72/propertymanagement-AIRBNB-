# Hide the "Edit with Lovable" badge

The badge is not part of your code — it is injected by Lovable into published deployments. It is currently enabled for this project.

## Step

- Turn badge visibility off for this project (set hide badge = true). This requires a Pro plan or higher and will show you an approval prompt.

## Notes

- No source files change.
- After the setting is applied, republish (or click Update in the publish dialog) so the live site is rebuilt without the badge.
- If your live site is served from your own Vercel deployment rather than Lovable hosting, the badge would not be injected there at all.
